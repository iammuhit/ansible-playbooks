## Ansible Playbooks

```bash
## 
# Running Playbooks & Templating
# 
# @see: https://docs.ansible.com/ansible/latest/playbook_guide/playbooks_intro.html
# @see: https://docs.ansible.com/ansible/latest/playbook_guide/playbooks_templating.html
# @see: https://docs.ansible.com/ansible/latest/playbook_guide/playbooks_handlers.html
# @see: https://docs.ansible.com/ansible/latest/playbook_guide/playbooks_vars_facts.html
# 
# ansible <hostname> -i inventory -m setup
# 
ansible-playbook --check playbook.yml -i inventory
ansible-playbook playbook.yml -i inventory

## 
# Nginx Installation & Configuration (Debian-based)
# 
# @see: https://docs.nginx.com/nginx/admin-guide/installing-nginx/installing-nginx-open-source/
# @see: https://docs.nginx.com/nginx/admin-guide/web-server/web-server/
# 
sudo apt update -y
sudo apt install nginx

sudo service nginx enable
sudo service nginx reload

## 
# Add hostname to local DNS resolver and access website
# 
echo '192.168.50.11 web.example.com' | sudo tee -a /etc/hosts
open http://web.example.com

## 
# Verifying Playbooks
# 
# @see: https://ansible.readthedocs.io/projects/lint/installing/
# @see: https://ansible.readthedocs.io/projects/lint/usage/
# 
brew install ansible-lint
ansible-lint playbook.yml
```
